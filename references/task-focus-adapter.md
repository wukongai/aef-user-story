# User Story任务适配
先按[AEF任务边界](task-focus.md)判断消息关系，再按[产品系统到故事](product-system.md)执行当前粒度。

| 当前工作 | 交付物 | 收口条件 |
|---|---|---|
| 全貌/粗故事/MVP | 多角色对象关系、流程、编号粗故事集合、选中/暂缓及理由、观察结果、依赖与确认状态 | 可以描述首轮完整闭环就提交候选；真实范围阻断明确提问，内容细节留后续 |
| 指定Story/AC | 对应卡片差异、修订、验收与确认状态 | 本轮指定改动已交付；不强制整库完成 |
| 纠偏/Skill反馈 | 当前偏差、适用规则、修正建议或失败记录 | 方法问题已回应，未获业务继续意图时不再追问产品内容 |

MVP范围确认不批准单条故事、验收或开发。用户只需范围稿时交付后结束；明确转产品详细设计或其他任务时保留故事固定引用并退出本Skill，由宿主按能力接续，不自行强留在Story阶段。
