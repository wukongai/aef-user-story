# AI 内容工作流

## 原始需求

AI 帮自媒体作者完成选题、写文章、配图、审核并发布。

## 信息边界

- facts：用户是独立自媒体作者，没有独立审核者。
- assumptions：首版由作者逐步确认每个产物。
- unknowns：发布平台范围。
- constraints：未经作者确认不能发布。

## Epic

EPIC-001：减少作者从选题到发布的重复工作；包含 US-001 至 US-004。

## User Stories

### US-001：获得候选选题

作为自媒体作者，当我准备新一期内容时，我希望根据主题获得候选选题，从而更快决定写什么。

### US-002：生成并修改文章草稿

作为自媒体作者，当选题已确认时，我希望获得可编辑文章草稿，从而减少从空白开始写作的时间。

### US-003：获得匹配正文的配图候选

作为自媒体作者，当正文结构稳定时，我希望获得与内容匹配的配图候选，从而完成文章视觉表达。

### US-004：确认内容后发布

作为自媒体作者，当正文和配图都准备好时，我希望本人确认后再发布，从而避免未审核内容上线。

四条 Story 的 INVEST 六项均通过；每条只描述一个用户结果。

## Acceptance

### AC-US-001-S：获得选题
- Given 已提供主题和受众；When 请求候选选题；Then 返回可区分的选题及理由。

### AC-US-001-F：选题生成失败
- Given 生成服务失败；When 请求候选选题；Then 显示失败并允许重试。

### AC-US-001-B：输入信息不足
- Given 未提供主题或受众；When 请求候选选题；Then 提示补充必要信息而不编造方向。

### AC-US-002-S：生成可编辑草稿
- Given 选题已确认；When 请求文章草稿；Then 返回可编辑且标明结构的草稿。

### AC-US-002-F：草稿生成失败
- Given 生成中断；When 作者查看结果；Then 保留已输入资料并允许重新生成。

### AC-US-002-B：引用缺少来源
- Given 草稿含无法确认来源的事实；When 显示草稿；Then 标记待核实而不当作确定事实。

### AC-US-003-S：获得配图候选
- Given 正文结构稳定；When 请求配图；Then 返回与段落用途对应的候选图。

### AC-US-003-F：配图生成失败
- Given 某张配图失败；When 查看候选；Then 保留成功结果并允许单张重试。

### AC-US-003-B：内容不适合自动配图
- Given 段落涉及敏感或不明确事实；When 请求配图；Then 标记需人工处理且不生成误导图。

### AC-US-004-S：确认后发布
- Given 正文和配图均已准备；When 作者逐项确认并点击发布；Then 发布已确认版本并返回结果。

### AC-US-004-F：发布失败
- Given 发布平台返回失败；When 作者发布；Then 保留已确认内容并显示重试入口。

### AC-US-004-B：存在未确认项
- Given 正文或配图仍有未确认项；When 作者尝试发布；Then 阻止发布并指出未确认项。

## 范围

- included：选题、草稿、配图候选、本人确认发布。
- excluded：独立审核角色、无人确认的全自动发布。
