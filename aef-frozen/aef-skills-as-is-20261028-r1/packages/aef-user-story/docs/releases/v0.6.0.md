## 安装与更新

直接使用优先执行 `npx skills add wukongai/aef-user-story`，由安装器选择宿主和project/global范围。Product整包执行 `npx skills add wukongai/aef-product`，其来源锁固定本版子包。二者按实际需要选择，避免重复暴露同一入口。需要回查固定源码时使用标签 `v0.6.0`。

源码维护使用Git仓库；安装副本按其管理方式更新，不直接编辑旧快照。已有业务故事数据无需迁移。
