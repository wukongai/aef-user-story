# MVP验证承接

## 产品内核与单元模型的验证承接

复用定义第三章的内核候选、第五章的经营单元及第六章验证计划，沿用已有Q和来源版本，不重做产品定义或商业问卷。只选择本轮最关键假设；局部故事不强制补全商业模型，缺上游资料也可先记录本轮假设与未知。
MVP范围说明每项选中能力服务于哪个内核要素或经营参数，并覆盖从入口到用户结果的必要依赖；暂缓项保留，不因“最小”自动删除需求。必要的人工交付也要记录真实时间、成本与未来复制限制。
使用MVP模板中的验证承接表：已有Q/来源版本 → 主张或参数 → 实验与观察口径/样本/周期 → 成功及反证条件与依据 → 证据和局限 → 回写章节。阈值未知可待定，不编数字，不把模板填完视为通过。
功能可用、用户获益、实际选择/付款、持续经营分别观察。满意不能证明付费，单位正贡献不证明整体盈利或可复制；一轮可只验证其中一项，明确其余未知。
验证结果回第三章内核或第五章模型，更新第六章计划及相关风险；新证据影响范围时展示差异请用户决定，不自动批准Story、AC或工程。独立使用且无定义文档时回写原假设记录，后续再关联主文。
