# aef-user-story v0.4.0

日期：2026-10-13。

用户故事从集中需求文档扩展为独立故事库：一条故事一张卡，总索引按Epic归类。日常阅读直接呈现完整故事原句和编号验收条件；版本和确认记录保存在对应独立数据中。

## 变化

- 默认故事库：index.md、stories/独立卡片、.story-data/独立历史、.story-library.json库与Epic信息。
- 新增和修改只更新有关文件；只调整Epic归类不重写故事正文。
- 稳定编号、追加修订、历史确认与旧格式兼容保留。
- 下游固定引用Story及AC版本，迭代无需复制正文。
- 迁移保留旧包；保存计划检查路径、符号链接、磁盘基线和人工编辑差异。
- 卡片显示完整statement原句，验收按1、2、3呈现；不重复铺陈管理字段。

## 验证与边界

发布前完整回归71项：70通过，1旧可选布丁投影跳过。
包含24项故事库测试、22项持续维护测试及旧格式回归。
独立评审发现的路径、退役验收引用和完整原句保留问题已修复并加入回归。

这是Skill与文档工具版本，不证明实际产品已实现或用户需求已批准。CLI仅输出候选计划；写入由宿主按授权处理。没有自动生成地图、迭代计划、Task或详细设计。

已有0.3故事库候选若需切换新展示，先备份并比较原卡与数据；人工修改不自动覆盖。旧v1/v2及workspace/v1仍使用原工具，不自动迁移。
父包快照与已安装副本不会自动升级。
