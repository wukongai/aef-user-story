# AEF User Story 0.7.0：本地封版说明

[返回使用入口](../../README.md) · [变更记录](../../CHANGELOG.md) · [方向审核](../../references/product-system.md#方向审核) · [故事确认](../../references/story-editing.md#user-story-明确确认)

本版新增从用户分类、阶段重要性和核心价值形成Epic与Story的主线，以及两个明确的人审节点。首次方向稿包含用户依据、Epic和少量真实代表Story，真人认可固定版本与范围后才批量写完整Story；完整Story按展示的ID/修订审核，通过后再正式AC及原型交接。MVP和保存授权不代批，AI意见不能产生真人批准。

认可记录沿用项目系统资料及原故事库机制，不新增数据schema、审批CLI或平行账本。方向或故事语义变化只影响相关认可，已有历史、固定引用、局部AC修改、有效决定恢复和下游边界保留。当前明确变更审核要求的授权需记录具体节点与范围，泛化自动授权不默认跳门。

本版为用户授权的本地封版；正式源码、固定分发包、Product适配和本机入口的实际状态以AEF本轮封版回执为准。未推送远端或公开发布；此文不宣称已完成真人研究或产品效果验证。结构、模拟对话、安装读回及真实效用分开报告。

升级保留0.6.0及原安装快照；回退须先保存升级后产生的业务资料，再恢复原只读快照指针。业务故事与AC修订是项目数据，与Skill版本独立，不能通过回退Skill静默重写业务记录。
