# 独立故事库案例（合成）
这是用于回归与查看的合成案例，不是真实用户批准或真实产品效果证据。

library/ 为当前可阅读的故事库：
- index.md 按两个Epic和未归类分组。
- US-001 为原逐字稿定位故事，原AC与修订完整保留。
- US-002 演示另一Epic下的故事。
- US-003 为未归类的候选。
- 每张卡片和数据只含自身故事与验收。

before/ 是修改前的可信基线；change-plan.json 是只修改 US-002 目标的计划。
library/ 已由计划逐项应用到合成样本，测试证明 US-001 与 US-003 文件字节未变。
story-reference.json 演示供下游保存的固定引用，不是迭代文档，不包含完整故事正文。
历史确认均来自synthetic合成记录，不得复制到实际项目冒充批准。

实际使用时从index.md进入某张故事卡，新增/修改只动目标卡数据与必要索引。
